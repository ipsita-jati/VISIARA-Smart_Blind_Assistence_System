To excute Smart System follow these steps:

1.Clone the project: git clone https://github.com/ipsita-jati/VISIARA-Smart_Blind_Assistence_System_app.git

2.Create a new virtual environment: py -3 -m venv .venv

3.Activate the new environment: .venv\Scripts\activate

4.Install dependencies from your file: pip install -r requirements.txt

5.run main file in any command prompt: python smart_blind_assistence_system.py
